# Identidad Vital VR

Referencia suministrada por el propietario: visor cyan con ECG rojo, Vital blanco,
VR rojo y fondo navy. `vital-vr-logo.svg` reproduce esa dirección como vector limpio.
No se ha descargado ni utilizado un logotipo de terceros.

Rutas reservadas para los archivos finales aprobados:
- vital-vr-logo.png
- vital-vr-logo-light.png
- vital-vr-mark.png

El diseño utiliza SVG hasta sustituirlo por los PNG aprobados; no hay imágenes rotas.
